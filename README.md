# The Local National: D.C. Conference Calendar

Conferences, summits and public forums in Washington, D.C. that show where national issues are headed. Updated every morning.

**Browse it:** https://offset-three-six.github.io/tln-dc-conferences/

This repository is the public, automatically updated output of The Local National's conference tracker. Every morning it checks D.C. venues, universities, think tanks and civic groups for in-person and hybrid conferences, summits and public forums. Editors verify the largest events each week.

## Use the data

Free to use, embed and republish with credit to The Local National (thelocalnational.com). Confirm details with the organizer before you go.

| What | URL |
|---|---|
| All public events (JSON) | https://offset-three-six.github.io/tln-dc-conferences/api/events.json |
| All public events (CSV) | https://offset-three-six.github.io/tln-dc-conferences/api/events.csv |
| Calendars and subscribe links | https://offset-three-six.github.io/tln-dc-conferences/api/calendars.json |
| One event (iCalendar) | https://offset-three-six.github.io/tln-dc-conferences/events/&lt;id&gt;.ics |
| One topic on the page | https://offset-three-six.github.io/tln-dc-conferences/?theme=housing |

Each event in `events.json` includes `id`, `title`, `start` and `end` (ISO 8601, Eastern time; date-only for all-day events), `when` (formatted in AP style), `location`, `organizer`, `format`, `cost`, `summary`, `event_url`, `registration_url`, `segments` (topic slugs), and `links` to add it to Google, Outlook or Apple Calendar.

## Embed it

The full calendar, resizing automatically:

```html
<iframe src="https://offset-three-six.github.io/tln-dc-conferences/embed.html" title="The Local National: D.C. Conference Calendar" style="width:100%;min-height:900px;border:0" loading="lazy" data-tlncc-frame></iframe>
<script>addEventListener('message',function(e){if(e.origin!=='https://offset-three-six.github.io'||!e.data||e.data.tlncc!=='height')return;document.querySelectorAll('iframe[data-tlncc-frame]').forEach(function(f){if(f.contentWindow===e.source)f.style.height=e.data.h+'px';});});</script>
```

A short list of upcoming events for one topic (`data-theme`) or everything:

```html
<div data-tln-conferences data-theme="all" data-limit="5"></div>
<script src="https://offset-three-six.github.io/tln-dc-conferences/widget.js" async></script>
```

On thelocalnational.com, the calendar is rendered natively by the WordPress plugin in `wordpress/tln-conference-calendar.zip` with the shortcode `[tln_conferences]`. Use `[tln_conferences theme="housing" limit="5" compact="yes" subscribe="no"]` for a sidebar list.
